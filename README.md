# Alaivan - Travel & Tourism Booking Website

A modern, responsive travel booking landing page built with pure HTML and CSS. Discover destinations, explore deals, and plan your perfect trip.

## 📋 Project Overview

**Alaivan** is a static travel and tourism website featuring:
- Hero section with integrated booking search form
- Popular destination showcase with CSS Grid layout
- "Book Your Next Trip" destination slider
- Last-minute hotel deals section
- Fully responsive design (desktop, tablet, mobile)
- Smooth hover animations and transitions

### Tech Stack
- **Frontend:** HTML5, CSS3
- **Icons:** Font Awesome 6.5.2
- **Typography:** Google Fonts (Inter)
- **Layout:** CSS Flexbox & CSS Grid

## 🎨 Design Features

### Color Scheme
- Primary Blue: `#00336c`
- Accent Blue: `#03a6ef`
- Dark Footer: `#0b0b0b`
- Borders: `#e5e7eb`

### Key Sections

**1. Hero Section**
- Full-screen background image with gradient overlay
- Navigation bar (logo, menu, sign-in button)
- Tagline & call-to-action text
- Booking search form with inputs for:
  - Destination (text input)
  - Check-in date (date picker)
  - Check-out date (date picker)
  - Number of travelers (number input)
  - Travel type tabs (Stays, Flights, Hotels, Restaurants)

**2. Destinations Section**
- "Traveler's Favourite" heading
- CSS Grid gallery (4 cards with asymmetric layout)
- Hover zoom effect on images

**3. Book Your Next Trip**
- Category filters (Famous Area, Mountains, Cities, Nature & Wildlife)
- Horizontal card slider (300px width)
- Destination card layout with image + info

**4. Last Minute Deals**
- Deal card slider (300px width)
- Hotel information cards with:
  - Hotel image
  - Name, location, ratings
  - Original & discounted prices
  - Route information

**5. Footer**
- Dark background with white text
- 4-column link grid (Available Countries, Company, Policies, Help)
- Social media links
- Legal links & copyright

## 📱 Responsive Breakpoints

```css
/* Tablet: Max 900px */
- 2-column grid for destination & deal sliders
- Full width cards

/* Mobile: Max 600px */
- Single column grid
- Hidden navigation links (max 800px)
- Full width cards
```

## 🎨 Customization

### Change Primary Color
Replace `#00336c` with your desired color throughout `style.css`

### Update Navigation Links
Edit the `<li>` elements in the navbar section of `index.html`

### Replace Images
Swap image files in the `/images` folder (maintain same filenames or update src paths)

### Modify Destination/Deal Cards
Update card content in the respective slider sections

## 📝 Notes

- All links are currently placeholder (`href="#"`)
- No backend functionality (contact forms, bookings not processed)
- Optimized for modern browsers (Chrome, Firefox, Safari, Edge)
